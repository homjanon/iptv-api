# 为什么文件名带 user_ 前缀：
#   iptv-api 源码 utils/tools.py 有通用覆盖机制——同目录存在 `user_<原文件名>`
#   就用它替代原文件。官方 CHANGELOG 也建议工作流用户这么做，避免 sync 上游时被覆盖。
#
# 本版相对第 1 版的改动与依据（全部为 2026-10-06 实测）：
#   ＋ 新增 hujingguang/ChinaIPTV：唯一提供了 CCTV-4K 候选的源（此前 CCTV-4K 有效 0）
#   － 移除 iptv-org/iptv 两个分支：英文/拼音命名，与中文频道白名单命中率极低
#   － 移除 live.hacks.tools ipv4：与 vbskycn 内容体积完全相同，纯镜像
#   － 移除 vbskycn / hacks 的 ipv6：两条都是 268 B 空壳，只有一条广告占位
#   － 移除 Guovin/iptv-database：404，该仓 2026-01-04 后无提交
#
# 方括号里是「独家接口数」＝该源提供了别的源给不了的接口（用同一套白名单增量计算）。
