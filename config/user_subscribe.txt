# polo 自用 IPTV 订阅源
# ------------------------------------------------------------------
# 为什么文件名是 user_subscribe.txt：
#   iptv-api 有个通用覆盖机制（utils/tools.py 的 resource_path）——
#   对任何配置路径，只要同目录存在 `user_<原文件名>`，就用它替代原文件。
#   所以 user_subscribe.txt 会覆盖 subscribe.txt，而 `Sync fork` 不会碰它。
#   官方 CHANGELOG 也是这么建议的：「工作流用户为了避免冲突覆盖，建议文件重命名添加 user_ 前缀」。
#
# 以下 5 条均于 2026-10-06 实测有效（体积与条目数已核实），
# 已剔除 3 条无效源：live.hacks.tools 的 ipv4（与 vbskycn 内容完全相同，纯镜像）、
# vbskycn 与 live.hacks.tools 的 ipv6（各 268 B 空壳，只有广告占位）。
# ------------------------------------------------------------------
