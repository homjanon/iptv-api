# polo 自用频道别名
# ------------------------------------------------------------------
# 为什么叫 user_alias.txt：同 user_subscribe.txt，靠 user_ 前缀覆盖 config/alias.txt。
# 源码依据：utils/constants.py 里 alias_path = "config/alias.txt"，
#          而 utils/tools.py 的 resource_path() 会用同目录的 user_alias.txt 替代它。
#
# 格式（官方规定，英文逗号分隔）：
#   模板频道名称,别名1,别名2,别名3
# 含义：模板里写的那个名字，在源里出现下列写法时也算同一个台。
#
# 为什么需要它：iptv-api 内置别名表有 7254 条，已覆盖「TVB翡翠台→翡翠台」这类常见写法
#（实测翡翠台/明珠台/无线新闻台都能正常产出）。但港澳台源的命名特别杂，
# 这批是实测从本次运行的「未匹配频道日志」里捞出来的真实写法，内置表没覆盖。
# ------------------------------------------------------------------
