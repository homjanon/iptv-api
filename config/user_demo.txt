# polo 自用频道模板
# ------------------------------------------------------------------
# 为什么叫 user_demo.txt：同 user_subscribe.txt，靠 `user_` 前缀覆盖 config/demo.txt，
# 这样 `Sync fork` 更新上游代码时不会和你的自定义内容冲突。
# 记得在 user_config.ini 里把 source_file 指向本文件。
#
# 格式（官方规定，必须是英文逗号）：
#   分类名,#genre#
#   频道名
#   频道名
# ------------------------------------------------------------------
# 说明：这里只写「你想要哪些台」，具体接口由订阅源提供，会被测速自动筛优。
# 所以某个台在你源里有别名（如 CCTV1 / CCTV-1 综合），只写标准名即可，
# iptv-api 内置 7254 条频道别名会自动归一化。
# ------------------------------------------------------------------
